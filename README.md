# Nooks Forecast walkthrough

Interactive teaching demo with synthetic data: submissions, scheduled snapshots and team rollups. No app, CRM or database connection.

Open index.html with team-rollup.js and configuration.js in the same folder, or use the GitHub Pages site.

The Metrics, boards & columns lesson is available at https://ohrobin-nooks.github.io/nooks-forecast-walkthrough/#configuration. It shows how shared calculations and board/column filters combine using synthetic deals.
